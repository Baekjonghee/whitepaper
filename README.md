# 매일 성경 묵상 웹앱

오늘의 성경 구절과 묵상 카드를 보여주는 반응형 Next.js 웹앱입니다.

## 기술 스택
- Next.js
- TypeScript
- Tailwind CSS

## 시작 방법
```bash
npm install
cp .env.example .env.local
npm run dev
```

브라우저에서 `http://localhost:3000` 접속

## 주요 화면
- 홈 화면
- 오늘의 말씀 카드 화면
- 즐겨찾기 화면
