# 말씀나눔

같은 말씀을 함께 묵상하고 기도제목과 감사나눔을 남기는 반응형 Next.js 웹앱입니다.

## 기술 스택
- Next.js
- TypeScript
- Tailwind CSS

## 시작 방법
```bash
npm install
cp .env.example .env.local
npm run dev
```

브라우저에서 `http://localhost:3000` 접속

## 주요 화면
- 홈 화면
- 오늘의 말씀 카드 화면
- 즐겨찾기 화면
- 가족 피드 화면
- 지난 말씀 상세 화면
